# Версия 1.4.3: обычные вопросы без регистрации задачи

Обработчик Codex больше не требует регистрировать отдельную задачу для обычного вопроса после завершения предыдущей работы. Раньше любое новое сообщение получало признак ожидающего запроса, а обработчик завершения ответа считал этот признак незавершённой работой. Поэтому даже просьба объяснить результат могла блокировать ответ.

Теперь сообщения после завершения или отмены задачи сохраняются как контекст и не возобновляют старую работу. После сжатия завершённая запись явно обозначается как прошлый контекст. Требование продолжить выполнение применяется только к активным и ожидающим задачам.

Вопрос во время незавершённой работы сохраняет её цель, следующий шаг и существующие операции. При принятии новой работы ведущий сохраняет её отдельно: автоматически через запуск Council либо командой `begin` для самостоятельной задачи. Обработчик не определяет новую задачу по каждому сообщению.

Также исправлено завершение самостоятельных задач. Для них достаточно непустого результата и отсутствия незавершённых шагов и операций. Создавать проверку Council для этого не требуется. Если проверка Council уже назначена, исходная задача обязана пройти её; удалить или заменить привязку для обхода проверки нельзя.

## Что проверено

- До исправления новые проверки воспроизвели четыре ошибки на прежнем коде. После исправления весь набор из 191 автоматического Python-теста прошёл. Тесты используют подменные программы и не обращаются к моделям.
- На сохранённом примере завершённой задачи обычный вопрос воспроизведён через публичную команду обработчика. Прежний обработчик блокировал ответ, исправленный пропустил его без создания новой задачи. Вопрос остался доступен при восстановлении контекста.
- В той же беседе, где готовилось исправление, выполнено реальное сжатие контекста. Поручение, следующий шаг и уже запущенная проверка восстановились без напоминания пользователя и без повторного запуска. Состояние исторического помощника, его сессии и счётчики сохранились.

- Перед выпуском повторно прошли 33 проверки обработчика, восстановления и установки. Из 85 тестов встроенного компонента 81 прошёл в песочнице; четыре проверки локального сервера прошли при повторном запуске без ограничения песочницы на локальные соединения.

## Границы проверки

Обычный вопрос проверен воспроизведением событий обработчика на сохранённой записи, а не отдельным новым пользовательским ходом в интерфейсе. Восстановление незавершённой работы проверено реальным сжатием беседы. Эти результаты не доказывают доставку штатных событий обработчиков во всех открытых чатах Codex. Независимый путь восстановления через глобальные инструкции, добавленный в 1.4.2, сохранён.

Изменено поведение обработчика Codex. Обработчики сессий Claude Code не менялись. Номера версии в манифестах согласованы с общим выпуском.

## Обновление

Выполните в каталоге, содержащем клонированный репозиторий:

```bash
git -C codex-claude-council pull --ff-only
python3 codex-claude-council/scripts/install.py --replace
```

Установщик сохраняет предыдущую версию в резервной копии. Перезапуск помощника и повторное создание его задачи для обновления не требуются.

Для обновления пакета в Claude Code:

```text
/plugin marketplace update codex-claude-council
/plugin update codex-claude-council@codex-claude-council
/reload-plugins
```
