# Версия 1.4.2: восстановление после сжатия

Установщик добавляет порядок восстановления в действующие глобальные инструкции Codex. Когда после смены контекста отсутствует текущее поручение, ведущий находит сохранённую запись именно этого чата, сверяет её с последним реальным запросом и продолжает незавершённый шаг. Завершённая запись предыдущей задачи не возобновляется автоматически.

Существующие пользовательские инструкции сохраняются. Перед изменением создаётся резервная копия; повторная установка не добавляет второй блок. Установщик теперь явно сообщает, что проверка регистрации обработчиков в отдельном процессе не подтверждает их работу в уже открытой беседе.

## Что проверено

В той же беседе, где готовилось исправление, выполнена реальная смена контекста. После неё ведущий самостоятельно восстановил актуальное поручение и завершил оставшиеся проверки в рамках исходного запроса, без напоминания пользователя. Новый помощник не запускался. Сохранённое состояние помощника совпало побайтово, его сессии и счётчики не изменились.

Все 185 автоматических Python-тестов прошли. Отдельная проверка комплектации установленного навыка также прошла. Автоматические тесты используют подменные программы и не обращаются к моделям. Установленные файлы исправления сверены с проверенным исходным кодом.

## Ограничение

Точная внутренняя причина, по которой штатные обработчики Codex не получили события в проверенной беседе, не установлена. Исправление обеспечивает независимый путь восстановления через глобальные инструкции. Успешное продолжение этой беседы не доказывает исправление штатных обработчиков и не гарантирует поведение всех будущих сеансов.

## Обновление

Выполните в каталоге, содержащем клонированный репозиторий:

```bash
git -C codex-claude-council pull --ff-only
python3 codex-claude-council/scripts/install.py --replace
```

Предыдущая установленная версия сохраняется в резервной копии. Перезапуск помощника и повторное создание его задачи для обновления не требуются.

Описание проверки опубликовано без исходной переписки, локальных журналов, имён компьютеров, пользовательских путей и идентификаторов беседы или сессий.
